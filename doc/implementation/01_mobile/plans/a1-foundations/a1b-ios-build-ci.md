## Goal

`make xcframework` builds a `GageFFI.xcframework` for the iOS device and
simulator, with an iOS 18 deployment target throughout, plus the
generated Swift. A macOS CI job builds it and runs a Swift smoke test in
a simulator.

On iOS and Android, gage is built without git2's `ssh` feature, and an
SSH remote is refused up front with a typed error that points at HTTPS.

## Where things are

- **Dependencies.** `ssh` is on for every target. `libssh2-sys` is a
  dependency on every Unix, iOS and Android included. git2 itself
  depends on `openssl-sys` on every Unix but macOS, so OpenSSL may stay
  linked on iOS without `ssh`.
- **The spike's measurements** (debug, then release):
  - `libgage_ffi.a`: 163 MiB, then 42.7 MiB
  - a linked Swift smoke executable: 15.0 MiB
- **Link needs:** `-liconv`, `Security`, `CoreFoundation`.
- **Without `IPHONEOS_DEPLOYMENT_TARGET`,** the vendored C objects are
  built for the SDK version (27.0).
- **CI:** none for mobile. dist already uses `macos-15` for Apple
  silicon.

## Decisions to make first

1. **How SSH is refused on mobile.**
   - Proposal: resolving the auth method for an SSH remote returns a
     new `remoteauth::Error::SshUnsupported` with kind `Usage` and
     `Remedy::UseHttps`, before any network.
   - The check is a pure function of the target OS, so host tests cover
     both answers.
   - `Cred::ssh_key_from_agent` is never reached on mobile.
   - Record it as ADR-0061, amending ADR-0015.
2. **How `ssh` is turned off.**
   - Proposal: `git2` without `ssh` in `[dependencies]`.
   - `ssh` is added back in a
     `cfg(not(any(target_os = "ios", target_os = "android")))` table,
     as is `libssh2-sys`.
   - Resolver 3 enables a target table's features only when building
     for that target, so desktop builds are unchanged.
   - Confirm with `cargo tree --target` before relying on it.
3. **OpenSSL on iOS.** Proposal: measure what stays linked without
   `ssh`. If `openssl-sys` remains only because git2 names it, record
   the size in the ADR and leave it. Patching git2 is out of scope.
4. **Simulator architectures.** Proposal: `arm64` only. GitHub's macOS
   runners and every current Mac are Apple silicon. Intel simulators
   are dropped.
5. **Generated Swift is not committed.** Proposal: it is generated by
   the build into `target/ios/`, from the same UniFFI version as the
   library, so it can't drift. The app consumes the build's output.
6. **When the CI job runs.** Proposal: on every pull request and on
   `main`, unfiltered. Nearly every change touches `crates/gage`, which
   this build compiles, and a path filter that misses one would let the
   iOS build break unseen. Whether it becomes a required check is a
   branch-protection setting, so it's the user's call.

## Tasks

### 1. No SSH on iOS or Android

- [ ] ADR-0061, linked from `doc/decisions/README.md`.
- [ ] Tests:
  - [ ] the method check, given a mobile target and an SSH remote,
    is `SshUnsupported` with `Remedy::UseHttps`, and makes no network
    call
  - [ ] given a desktop target, it is unchanged; the existing
    `remoteauth` tests stay green unedited
  - [ ] for `aarch64-apple-ios` and `aarch64-linux-android`, the
    library's resolved dependency graph has no `libssh2-sys`
    (`cargo metadata --filter-platform`, in `no_frontend_deps.rs`'s
    style)
  - [ ] for the desktop targets, it still does
- [ ] Implement: target tables in `crates/gage/Cargo.toml`; the gated
  refusal.
- [ ] Measure the iOS release archive and the linked smoke against the
  spike's numbers. Record them in the ADR.

### 2. `make xcframework`

- [ ] `scripts/ios/build-xcframework.sh`, run by `make xcframework`:
  - [ ] fails with a clear message if Xcode or the Rust targets are
    missing
  - [ ] builds `aarch64-apple-ios` and `aarch64-apple-ios-sim` release,
    with `IPHONEOS_DEPLOYMENT_TARGET=18.0`
  - [ ] generates the Swift bindings with the crate's `uniffi-bindgen`
  - [ ] writes `target/ios/GageFFI.xcframework` (two slices, headers
    and module map) and `target/ios/swift/`
  - [ ] fails if any object in either archive has a minimum OS other
    than 18.0
- [ ] `crates/gage-ffi/README.md`: what to install, and how to build.

### 3. Swift smoke

- [ ] `crates/gage-ffi/examples/smoke_fixture.rs` writes a vault with
  two entries into a directory, through A1a's `Vault::init`.
- [ ] `crates/gage-ffi/tests/swift/main.swift`, from the spike:
  - [ ] it opens, unlocks and lists
  - [ ] it checks the wrong-passphrase and unknown-vault errors
  - [ ] it exits non-zero on any mismatch
- [ ] `make ios-smoke` creates the fixture, boots a simulator, runs the
  smoke and shuts the simulator down.

### 4. CI

- [ ] `.github/workflows/mobile.yml` on `macos-15`:
  - [ ] SHA-pinned actions, so `check-action-pins.sh` passes
  - [ ] `contents: read`
  - [ ] runs `make xcframework` and `make ios-smoke`
- [ ] Green on this milestone's PR. The other workflows are unaffected.
